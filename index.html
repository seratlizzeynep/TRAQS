TRAQS

Requirements management and traceability for safety-critical projects, with a local AI agent that helps and never decides on its own.

CMPE 491 · Senior Design Project I · TED University · 2026–2027 Fall

About the Project

TRAQS is a web-based application that lets developers manage and trace requirements in projects involving safety-critical products, such as those in the defense, medical and aerospace industries. Requirements are defined hierarchically, linked to test cases and to each other, and kept under controlled change.

Key Features

🗂️

Hierarchical requirements

Define and organize requirements in a structured, multi-level hierarchy.

🔗

Traceability links

Connect requirements to test cases and to each other for end-to-end traceability.

⚠️

Impact analysis

Identify related requirements automatically when something changes.

📌

Baselines

Freeze and compare the state of requirements at key project milestones.

✅

Role-based approval

Changes go through an approval workflow based on user roles.

🔄

Excel & ReqIF exchange

Import and export data to work with partners and other tools.

AI Agent

TRAQS integrates an AI agent that supports the requirements engineering process. It runs locally using a language model, and every suggestion requires user approval.

Analyze documents

Reads project-related documents and generated requirements.

Classify by domain

Categorizes requirements by domain, such as defense or medical.

Evaluate & rewrite

Assesses quality and rewrites requirements to the standards of the selected domain.

Propose links

Suggests links between requirements and test cases for the user to review.
